## 3. 極簡鳥寶建檔

- [x] 3.1 建立鳥寶建檔表單，提供名字、品種、體重（克）與飲食類型欄位，送出時產生唯一 `bird_id` 並帶回首頁；驗證方式：完成一筆有效資料後，首頁顯示名稱、品種色票、體重與飲食群組。
- [x] 3.2 加入必填欄位、空白名字、重複名稱、空值／空白／零值／負數／非數字體重與不支援品種的白話錯誤提示；驗證方式：逐一輸入或貼上錯誤值，確認表單不保存不完整資料、保留可修正內容，且體重錯誤文字明確要求輸入大於 0 的克數。
- [x] 3.3 完成體重欄位的手機輸入與送出防呆；驗證方式：確認欄位顯示「克」、使用數字鍵盤友善設定（`inputmode="decimal"`），可接受有效小數但拒絕 `NaN`／無限值、0 與負數，且瀏覽器限制失效時仍由送出前驗證攔截。
- [x] 3.4 完成表單焦點、錯誤關聯與返回／送出動線；驗證方式：送出含錯誤資料時焦點移到第一個錯誤欄位、錯誤可被讀屏工具讀到、其他欄位內容保留；有效送出回首頁，返回不保存且有未保存確認。
- [x] 3.5 驗證多鳥資料隔離與重新整理恢復；驗證方式：建立兩隻同名或不同品種鳥寶後重新整理，確認兩筆 `bird_id`、名稱與色票都維持獨立。
