# Sprint 2 Bottom Menu 驗收步驟

1. 以瀏覽器開啟 `index.html`，將視窗調整為 390 × 844。
2. 確認底部固定顯示「首頁、鸚鵡檔案、照顧紀錄、鳥聚點」四個入口，且四個入口都可點擊。
3. 依序點選四個入口，確認頁面不重新整理、目前入口有選取狀態，且照顧紀錄與鳥聚點顯示簡約空狀態。
4. 在「鸚鵡檔案」與其他分頁間來回切換，確認底部導覽仍在、頁面內容沒有被導覽列遮住。
5. 點選首頁的「查看鸚鵡檔案」或「建立第一隻鳥寶」，確認會回到正確的鸚鵡檔案流程。

視覺檢查：背景使用 `#F8EADC`，主色使用 `#09251C`，強調色使用 `#A55704`；導覽項目的可操作高度至少 44px。
